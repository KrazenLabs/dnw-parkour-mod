# Drag'n'Wash Parkour Mod

Run, jump and fly around like the professional kobold you are! This mod adds sprinting, double jumps, wall-runs and wall jumps for super fun movement!

# Installation

Simply download the [latest version of the DnW Mod Manager](https://github.com/KrazenLabs/dnw-modmanager/releases/latest), which will let you install the mod directly. No separate download needed!

# Usage

Left Shift (or left stick click on a controller) to sprint, double jumps, wall-runs, etc. work like you would expect from parkour games :)

# How to uninstall

Just remove it using the Mod Manager.
